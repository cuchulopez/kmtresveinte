Activity 1: All About Me! 🎒

Read and fill in the blanks. Circle the correct word.

Hello! My name is .

I am years old.

Look at my school bag! I have got a ( pencil / car ) and a ( ruler / dog ).

I haven't got a ( book / dinosaur ) in my bag. My favourite toy is a kite!

Activity 2: Animal Magic! 🦁🐮

Read and match the animal to the description. Draw a line!
  • 1. It is a wild animal. It is big and grey. It can walk but it can't fly.               A) COW
  • 2. It is a domestic animal. It is small. It can jump and catch mice!                  B) ELEPHANT
  • 3. It is a farm animal. It is black and white. It can walk.                              C) CAT

Activity 3: My Town & Jobs 🏥⚽

Look at the sentences. Circle the correct option.
  • 1. Look! ( There is / There are ) a big hospital in my town.
  • 2. A ( teacher / doctor ) works in the hospital.
  • 3. ( There is / There are ) two parks next to the school.
  • 4. I play football in the park. Football is a ( sport / shape ).

Activity 4: What can YOU do? 🏃‍♂️

Write true sentences about you. Use "I can" or "I can't".
  • 1. (swim) ____________________________________________________
  • 2. (fly) _______________________________________________________
  • 3. (jump) _____________________________________________________

Activity 5: The Magic Calendar 📅

Write the missing days, months, and numbers!
  • 1. Days: Monday, _______________, Wednesday, _______________, Friday.
  • 2. Months: _______________, February, March, _______________, May.
  • 3. Numbers: ten, twenty, _______________, forty, _______________, sixty.

Activity 6: Read and Draw! 🎨

Read the sentences very carefully and draw the picture in the box.
  • 1. Draw a big blue circle.
  • 2. Draw a red book in front of the circle.
  • 3. Draw a yellow pencil next to the book.

Teachers & Parents: Answer Key 🔑

Activity 1: Child's name / Child's age / pencil / ruler / dinosaur.

Activity 2: 1 -> B (Elephant) / 2 -> C (Cat) / 3 -> A (Cow).

Activity 3: 1. There is / 2. doctor / 3. There are / 4. sport.

Activity 4: 1. I can/can't swim. / 2. I can't fly. (Expected) / 3. I can jump.

Activity 5: 1. Tuesday, Thursday / 2. January, April / 3. thirty, fifty.

Activity 6: The drawing should show a blue circle. In front of it (overlapping or below), a red book. To the side of the book, a yellow pencil.
